# AI Companion

## Prototype v0.1

Features:

* Active window detection
* Context categorization
* Activity history tracking
* Context-aware LLM prompts
* Recent workflow awareness

Limitations:

* No UI Automation
* No session detection
* No browser tab extraction
* No audio understanding
